# New Town Site Suitability Analysis

## Project Overview

This project demonstrates the application of Geographic Information Systems (GIS) in spatial suitability analysis for urban planning and development.

The study focuses on identifying potentially suitable areas for new town development through GIS-based spatial analysis and suitability mapping.

## Project Objectives

- Assess spatial suitability for potential urban development.
- Identify and visualise areas with different levels of suitability.
- Demonstrate the application of GIS in land-use planning and spatial decision-making.

## Project Output

A thematic site suitability map illustrating the spatial distribution of suitability classes for potential new town development.
